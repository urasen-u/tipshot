[プロジェクト概要]
企画・UI設計・プログラム実装・リリースまでを一人で完遂したUnityゲームです。

【使用技術・環境】

・Engine: Unity 202x.x

・Language: C#

・Version Control: Git / GitHub

[ゲーム概要]
6体の仲間を射出して、敵を全滅させるゲームです。一度射出した仲間は、倒されるまでは画面に残り、
他の仲間で当たって弾くことでさらに敵にダメージを与えることが出来ます。
全ての仲間を射出するか、画面内の敵をすべて倒すことが出来れば、次のステージへ進み、
合計で3ステージをプレイして、よりハイスコアを目指しましょう！

[技術的背景]
・Editor拡張の実装
Editor拡張を用いて配置した敵のリセットなどを効率的に行うことが出来るようになりました。


・ヒットストップの実装
敵に攻撃が当たったときのヒットストップを実装することに成功しました。
それにより、より攻撃のインパクトを強調することに成功しました。

・攻撃時の演出の実装
攻撃がヒットした時にエフェクトが発生し、より戦闘を描写を豪華にすることが出来ました。
